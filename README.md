# Production Desk

A production planning demo built with n8n, Groq, and FastAPI.

Built by [Khaled Abdulrahman](https://github.com/kira924).

Submit a structured production brief, receive a verified estimate, and explicitly approve or decline it. An approved estimate creates one synthetic work order. All prices, availability rules, and orders use demo data.

This repository contains the separate web-facing version of the project. Docker setup, the browser interface, and documentation are developed here with their own commit history.
